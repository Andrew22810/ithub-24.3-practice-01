## 6. Обнаруженные нарушения и исправления

### 6.1. Нарушение R2 — допустимое количество 3

- Тест: `test_valid_quantities`.
- Данные: выдача 3 микрофонов.
- Ожидаемый результат: успешная выдача, остаток микрофонов становится равен 0.
- Фактический результат до исправления: программа отклоняла количество 3.
- Причина: верхняя граница количества была проверена как строгое условие меньше 3, поэтому допустимое значение 3 не проходило проверку.
- Файл с результатом до исправления: `before_03.txt`.
- Исправление: проверка верхней границы изменена так, чтобы значение 3 включалось в допустимый диапазон.
- Результат после исправления: тест пройден.

### 6.2. Нарушение R3 — недостаточный остаток оборудования

- Тест: `test_insufficient_stock_does_not_change_state`.
- Данные: запрос 2 штативов при наличии 1.
- Ожидаемый результат: отказ с сообщением «Недостаточно оборудования», состояние не меняется.
- Фактический результат до исправления: программа принимала запрос.
- Причина: проверялось наличие хотя бы одной единицы оборудования, а не достаточность остатка для всего запрошенного количества.
- Файл с результатом до исправления: `before_03.txt`.
- Исправление: проверка остатка выполняется относительно запрошенного количества.
- Результат после исправления: тест пройден; состояние при отказе не изменяется.

### 6.3. Нарушение R6 — повторный возврат

- Тест: `test_repeated_return_does_not_change_state`.
- Данные: выдача одной единицы оборудования, первый возврат, затем повторный возврат той же записи.
- Ожидаемый результат: повторный возврат отклоняется с сообщением «Уже возвращено», состояние не меняется.
- Фактический результат до исправления: повторный возврат принимался.
- Причина: перед возвратом не проверялся текущий статус записи.
- Файл с результатом до исправления: `before_03.txt`.
- Исправление: добавлена проверка статуса; уже возвращённая запись не обрабатывается повторно.
- Результат после исправления: тест пройден; история и остаток не меняются при повторном возврате.
