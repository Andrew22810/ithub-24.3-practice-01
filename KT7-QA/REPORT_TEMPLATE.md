Требование: T06 — Reporter List excludes another author's incident in the same team.

Входные данные: два пользователя с ролью Reporter из команды alpha. Каждый создаёт собственный инцидент. Первый Reporter запрашивает список.

Ожидаемое поведение: в списке первого Reporter присутствует только его собственный инцидент.

Фактическое поведение: список содержит оба инцидента, включая инцидент второго автора.

Имя падающего теста: Reporter_list_does_not_contain_another_authors_incident.

Причина: в IncidentDeskService.List для роли Reporter используется фильтр только по TeamId. Не проверяется ReporterId.

Самый важный оставшийся непроверенный риск: T07, T08, T10, T13, T15 и T17. В частности, не проверены запреты доступа Responder и Coordinator к чужой команде, запрет назначения Responder из другой команды и запрет начала работы не назначенным Responder.

Сравнение покрытия кода: покрытие строк выросло с 72,54% до 85,29% (+12,75 процентного пункта), покрытие ветвей — с 44,00% до 56,00% (+12 процентных пунктов). Рост покрытия кода сам по себе не доказывает корректность авторизации.

Решение о выпуске: выпуск не рекомендуется. Тест T06 выявил подтверждённое нарушение изоляции инцидентов между авторами одной команды. Остальные три новых сценария прошли, однако часть правил авторизации и переходов состояний осталась непроверенной. Дефект следует исправить и повторно выполнить тесты перед выпуском.
