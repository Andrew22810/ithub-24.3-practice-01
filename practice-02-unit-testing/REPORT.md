## Найденные дефекты

### DEF-001. Скидка по сумме не применяется при ровно 5000 рублях

- Нарушенное требование: R2.
- Входные данные: subtotal = 5000, loyalty = false, express = false.
- Ожидаемый результат и расчёт: 5000 × 0.95 = 4750; доставка бесплатна, итог = 4750.
- Фактический результат: 5000.
- Имя теста: Discount_Exactly5000_DiscountIsApplied.

Причина: при достижении порога 5000 рублей скидка 5% должна применяться включительно, но фактическая реализация её не предоставляет.

### DEF-002. Скидки складываются вместо выбора большей

- Нарушенное требование: R3.
- Входные данные: subtotal = 6000, loyalty = true, express = false.
- Ожидаемый результат и расчёт: применяется только скидка 10%; 6000 × 0.90 = 5400. Обычная доставка бесплатна.
- Фактический результат: 5100.
- Имя теста: LoyaltyAndAmountDiscount_Only10PercentApplied.

Причина: реализация складывает скидку 5% по сумме и скидку 10% по карте. По требованию должна применяться только большая скидка — 10%.

### DEF-003. Экспресс-доставка становится бесплатной при сумме от 4000 рублей

- Нарушенное требование: R5.
- Входные данные: subtotal = 4500, loyalty = false, express = true.
- Ожидаемый результат и расчёт: скидки нет; товары = 4500; экспресс-доставка = 500; итог = 5000.
- Фактический результат: 4500.
- Имя теста: ExpressDelivery_4500_StillCosts500.

Причина: реализация применяет правило бесплатной обычной доставки к экспресс-доставке, хотя экспресс-доставка всегда должна стоить 500 рублей.
